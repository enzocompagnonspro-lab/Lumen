# LUMEN-REAL-01 — GOLDEN JOURNEY

Mission: construire une seule traversée complète et exceptionnelle avant d'étendre le monde.

**Sanctuaire → lecture réellement sourcée → réflexion → geste → sortie dans le réel → retour → transmission.**

Principes de sortie :
- préserver le Golden Sanctuary ;
- une lecture disponible = texte réel, sources, limites, exemple, reformulation ;
- un clic ne vaut pas compréhension ;
- une intention n'est pas une action ;
- un retour utilisateur reste SELF_REPORTED ;
- la transmission contient une source et une limite ;
- desktop, mobile, clavier et mouvement réduit doivent être vérifiés ;
- aucune publication ni changement canonique sans revue indépendante puis Human Gate.
