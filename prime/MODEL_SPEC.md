# LUMEN PRIME — MODEL SPEC

LUMEN PRIME is not a frontier model trained from zero. It is the strongest practical model architecture for LUMEN: one powerful reasoning core governed by canon, persistent state, specialist routing, source discipline, evaluation gates and tool use.

## Architecture
USER/UI → GOVERNOR → Canon Loader + State Loader + Router → up to 3 experts → synthesis → canon/evidence checks → Reviewer → Answer/Action/Human Gate.

## Memory
- session state
- user journey state
- immutable canon state
- sourced knowledge graph
- evidence ledger
- production/QA state

## Why this is stronger for LUMEN
Raw intelligence alone is not enough. LUMEN needs provenance, visual integrity, persistent progression, long-horizon memory, tool execution, production QA and Human Gates.

## Upgrade path
V1 orchestration/evals → V2 retrieval over full knowledge base → V3 persistent database/user-state graph → V4 multimodal scene/video understanding → V5 optional fine-tune after enough reviewed examples.
