# LUMEN PRIME V2 — Memory & Knowledge Graph

## Four memory classes
- **Canon memory**: approved LUMEN doctrine and immutable references.
- **Knowledge graph**: categories, contents, concepts, chambers and typed relations.
- **Journey memory**: user progress, readings, rituals and unlocks.
- **Evidence ledger**: every important state transition carries OBSERVED / REPORTED / INFERRED / UNKNOWN provenance.

## Graph relations used in V2
- `BELONGS_TO`
- `NEXT`
- `UNLOCKS`

The schema is intentionally extensible for future relations such as `EXPLAINS`, `CONTRADICTS`, `REQUIRES`, `PRACTICES`, `AUTHORED_BY`, and `SUPPORTED_BY`.

## Privacy / authority
Memory writes are local by default. Public release, canonical changes and irreversible external writes remain gated.
