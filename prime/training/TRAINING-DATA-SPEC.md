# Training Data Spec

Do not fine-tune prematurely. Future data should contain reviewed examples of sourced explanations, VOIR→COMPRENDRE→AGIR transformations, journey decisions, visual canon accept/reject cases, practice generation and independent reviews.

Before fine-tuning: at least 5,000 reviewed examples, <1% evidence-label disagreement, 100% human review on canonical-change examples, and a held-out eval set never used for training.
