# LUMEN OS 1.7 REAL — GOLDEN JOURNEY

Cette candidate ferme le premier parcours complet **Du savoir au réel**. Le Golden Sanctuary est conservé comme seuil. Trois lectures sémantiques, un atelier, une sortie volontaire, un retour SELF_REPORTED et une trace de transmission sont intégrés.

## Démarrer
```powershell
Get-ChildItem .\scripts\*.ps1 | Unblock-File
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\scripts\START-GOLDEN-JOURNEY.ps1
```
