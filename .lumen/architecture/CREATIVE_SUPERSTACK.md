# CREATIVE SUPERSTACK

## Goal
Do not let any model's aesthetic become LUMEN's aesthetic.

LUMEN owns a provider-neutral `SceneSpec`.

## SceneSpec fields
- intent
- narrative beat
- canonical references
- composition anchors
- camera
- depth
- lighting
- palette
- character identity
- motion
- sound
- interaction
- forbidden drift
- desktop/mobile framing
- reduced-motion form

## Image tournament
For a Golden image:
1. Art Director creates one SceneSpec.
2. Candidate A: GPT-Image-2.
3. Candidate B: approved Gemini/Imagen path.
4. Candidate C: Adobe/partner path where relevant.
5. Normalize format/resolution.
6. Automated QA: landmarks, text defects, edge/artifact checks, reference distance.
7. Independent visual review.
8. Human selection.

## Video tournament
For a Golden shot:
1. ShotSpec + reference frames.
2. Veo 3.1 candidate.
3. Runway Gen-4.5 candidate.
4. Kling 3.0/Omni candidate when useful.
5. Compare identity continuity, physics, camera, prompt adherence, artifacts, audio.
6. Cost ceiling.
7. Human Golden Shot.

## Figma is the design source of truth
A generated image is not a design system.
Approved screens are decomposed into:
- tokens
- components
- semantic regions
- motion contract
- responsive constraints

Figma Code Connect links approved components to code.

## Adobe is the finishing room
Adobe is used for:
- high-precision edits
- compositing
- asset management
- comparing partner models in one workflow
- final finishing

It does not replace Figma as UI source of truth.
