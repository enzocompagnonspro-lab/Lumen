# KNOWLEDGE SUPERSTACK

## Source flow
Google Drive / web research
→ SourceRecord
→ extraction
→ ClaimRecords
→ independent contradiction search
→ KnowledgeObject
→ lesson
→ practice
→ Journey placement

## Retrieval
Use hybrid retrieval:
- PostgreSQL tsvector
- pgvector using text-embedding-3-large
- metadata filters
- graph edges
- final reranking/synthesis by Governor

## Editorial rule
AI may draft.
Canonical knowledge requires source verification and editorial review.

## Four-layer doctrine
Each lesson distinguishes:
1. FACT / SOURCE
2. INTERPRETATION
3. SYMBOL / METAPHOR
4. PRACTICE

## Personal data minimization
Initial cloud state stores progression metadata.
Raw private reflection text remains local-first until a separate privacy design is approved.
